# SFE Code Boundary Constraint

Only Developer agents are allowed to edit or write application source code files. 
Product Managers (PMs) and Designers/Architects are strictly restricted from modifying these files. 

If your active role is PM or Architect, you must halt execution and instruct the user to delegate the task to the Developer agent.
